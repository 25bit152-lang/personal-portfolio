# Personal Portfolio — Siranjeev D.

A responsive student portfolio built using **HTML, CSS, and vanilla JavaScript**.

## Files
- `index.html` — page content and sections
- `style.css` — responsive layout and visual styling
- `script.js` — mobile navigation, back-to-top control, and dynamic year

## Before publishing
1. Open `index.html` and replace `YOUR_EMAIL@example.com` with your real email.
2. Replace the GitHub profile link with your own public GitHub profile URL.
3. Check that the education, skills, and project descriptions accurately reflect your work.
4. Test the page in a browser at desktop and mobile widths.

## Run locally
Double-click `index.html` to open it in a browser. No build tools are required.

## Publish using GitHub Pages
1. Create a **public** repository on GitHub, for example `personal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the deployment to finish. The site URL usually looks like `https://YOUR-USERNAME.github.io/personal-portfolio/`.
7. Open the live URL in a private/incognito window and on your phone to verify it works.
